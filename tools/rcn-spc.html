3 · Subgrouping

Choosing a column here is a claim about cause: variation inside a subgroup becomes noise, variation between subgroups becomes signal.

4 · Process changes

Mark where the process was deliberately changed. Each phase gets its own centre line and its own limits, computed only from its own points, and the run rules restart at every boundary.

5 · Limits

Set limits from a stable stretch, then extend them forward to test whether later points belong to the same process. This asks a different question from a change point: freezing tests whether later points still belong; a change point declares that they do not.
