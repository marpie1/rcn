How to Use:

  • Add components: Type a name in "Component name" field and click "➕ Add Component"
  • Drag components: Click and drag any component to reposition it on the map
  • Select components: Click any component to select it (gets black outline)
  • Rename: Select a component, type new name in "New name for selected" field, click "✏️ Rename"
  • Add comments: Select a component, type comment in "Comment for selected" field, click "💬 Add Comment"
  • View comments: Hover over any component to see its comment in a tooltip
  • Color schemes: Choose "Evolution Stage" or "Value Chain Layer" to auto-color all components, or use "Custom" for manual colors
  • Change colors: Select a component, pick a color, click "Apply Color" (sets scheme to Custom)
  • Create connections: Check "Connection Mode", then click two components to connect them
  • Delete connections: Click "Remove Connection", then click on a dependency line
  • Delete components: Select a component, click "🗑️ Delete Component"
  • Reset: Use "Reset to AI Version" to restore the original AI-generated layout
  • Compare: Check "Show AI Original" to see your edits alongside the original
  • Export: Use "Export as PNG" to download an image, or "Export Map Data" for JSON
