Mech Blocks

Marc Pierson and Claude Opus 5.5 · October 2026

Build a Mech script by dragging blocks. The text on the right is what FedWiki stores, and it is rewritten on every drag. Type in the text and the blocks follow. Each block shows what it needs and what it makes, as an icon and a word. Three lamps say whether the script fits together, whether it can be started, and whether it ends in a result. In beginner mode a block that would not fit cannot be dropped.

Blocks

Drag onto the script, or tap to add at the blue line. Drag a block back here to remove it.

Script

Drag by the block's name; tap a name to put the blue line after it. Click the words after the name to edit them. Drop a wiki page link here to get a FROM block.

Before you run it

    This prototype does not run Mech. The checks use the trouble messages from Ward's own blocks, applied before the script runs instead of after. The state each block needs and makes comes from reading blocks.js; it lives below as a catalog that could move into Mech itself.
