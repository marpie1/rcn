1 · Starting it

The Sunburst reads the substrate, so the substrate has to be up. Two things must be running: Neo4j Desktop (the RCN SCHEMA server) and the projection API.

cd ~/rcn/substrate
python3 db.py --check          # is Neo4j reachable, and what is in it
python3 api.py                 # projections + the tools, port 8768

Then open http://localhost:8768/tools/schema-sunburst.html, or follow sunburst ← the vocabulary from the index at http://localhost:8768/.

Claude Code has full admin over the database but cannot start or stop the DBMS. If db.py --check says it cannot reach the endpoint, open Neo4j Desktop and start the server by hand.

The tool also opens straight off disk by double-clicking the file. It then draws a baked-in snapshot rather than the live graph — see §7.

2 · Reading the wheel

PartWhat it is
HubThe substrate, the graph you are reading, and the concept count.
Ring 1The eight families. Fill and the heavy radial divider both come from the :Family node's own palette.
Ring 2The schema label — the merge key two drawings agree on. Org, Problem, Action.
Ring 3The states of the concept — the ways it can be measured. Effectiveness of ORG. A concept with several states splits its ring-2 arc between them.
Arc widthBy default, the source count: in how many of this graph’s source drawings the concept appears.
TintEach ring outward is a paler mix of the same family hue. Depth, not a separate meaning.
Width is the whole message — but read it against the right graph. Every other sunburst you have seen sizes arcs by a quantity: bytes, dollars, headcount. This one sizes them by how many separate source drawings contain the concept.

What a source is differs per graph, and the wheel cannot tell you which you have open. In aspects16 the sixteen sources are topic drawings, so width means cross-cutting — this concept was needed in most aspects of one schema. In the neo4j reference the sources are people, and width there means agreement — the gold test. Do not carry the second reading onto the first graph.

A family's width is the sum of its children's, and is never stored — it is recomputed every time, so it cannot disagree with the concepts inside it.

3 · The controls

graph

Which database to read. The same Cypher runs against all three — the selector chooses which graph, never which query.

OptionWhat it holds
aspects16The 16 topic drawings with exact provenance — action, org, place, and so on. 24 concepts, 71 source mentions. The default. Sources here are aspects of one schema, not separate contributors.
composite26The signed EIP causal loop diagram — 25 concepts.
neo4jThe n=6 reference graph. Small on purpose: it is the permanent conformance test.

arcs — sources / equal

  • sources (default) — arc width is the source count. Concepts with no recorded source still get a minimum of one, so nothing collapses to an invisible sliver.
  • equal — every concept gets the same arc, like a classic type-hierarchy diagram. Use it once in a meeting to show what the weighting was doing, then switch back.
Flipping between the two is the fastest way to make the point to a group. In equal, Resource looks as established as Person. In sources, it shrinks to a sliver — and someone always asks why.

rings — 3 / 2

3 shows family → concept → states. 2 stops at the concept. Most concepts have exactly one state, so for them ring 3 is only the human phrasing — but where a concept has several (Affect is Positive and Negative), dropping ring 3 hides real structure. Two rings is still the better shape for a slide or a printed wall sheet.

4 · Hover and pinning

Labels are fitted to the wedge they sit in, and a wedge can be too thin to hold words. Rather than let text spill into a neighbour, the tool shortens it — and where nothing legible fits at all, prints a faint ….

Hover is therefore not decoration; it is where the text went. Every segment carries its full content regardless of what the ring managed to print:

  • the schema label
  • every state of the concept, in full
  • the family
  • the source count, and which sources

Click to pin the tooltip so it stays put — necessary on a touch screen, which has no hover, and useful when reading a long label without holding the mouse still. Click the same wedge again, or anywhere off the wheel, to release it.

The tooltip is deliberately near-transparent frosted glass rather than an opaque card, so the diagram stays readable underneath the thing describing it.

5 · Export

ButtonWhat you get
SVGVector, ~29 KB, with font-family declared on the text so labels do not un-wrap when the file is opened outside the browser. The right choice for print, for a slide, or for further editing.
PNGRaster at 2× the on-screen size, white background. The right choice for pasting into a document or a chat.

Both are named for the graph they came from — rcn-schema-sunburst-aspects16.svg — so an exported file always says which database it describes.

Exports capture the current toggles. An SVG saved in equal mode looks authoritative and is not showing evidence. Check the toggles before exporting anything that will outlive the meeting.

6 · URL parameters

?db=aspects16Open directly on a graph, skipping the picker. Accepts any database the API can reach.

That makes a specific reading linkable — useful in a wiki page or an agenda item where you want everyone looking at the same wheel.

7 · Offline snapshot

A snapshot of all three graphs is embedded in the HTML file. When fetch() cannot reach the API — opened over file://, or the server is down — the tool draws the snapshot instead and says so: the status turns red and reads offline snapshot with its capture date, and the footer changes to match.

The snapshot is a convenience, not a source. If it disagrees with the live database, the live database is right. The tool never pretends a stale reading is current.

Refreshing it

After the vocabulary changes materially — a new family, a batch of new concepts — re-bake it:

cd ~/rcn/substrate
python3 - <<'EOF'
import api, json, datetime, re
out = {'_captured': datetime.date.today().isoformat()}
for db in ('aspects16', 'composite26', 'neo4j'):
    out[db] = api.vocabulary_projection(db)
p = '../tools/schema-sunburst.html'
src = open(p).read()
blob = json.dumps(out, separators=(',', ':'))
new, n = re.subn(r'/\*__FALLBACK__\*/.*?/\*__END__\*/',
                 lambda m: '/*__FALLBACK__*/' + blob + '/*__END__*/', src, flags=re.S)
assert n == 1
open(p, 'w').write(new)
print('re-baked', len(blob), 'bytes')
EOF

The markers /*__FALLBACK__*/ and /*__END__*/ exist for exactly this. Do not hand-edit the blob between them.

8 · The projection

Everything the tool draws comes from one endpoint:

GET /projection/vocabulary?db=aspects16

It returns the substrate's standard envelope — {nodes, edges} in the Graph Tool's native schema — describing a tree: root → family → schemaLabel → variableLabel. Each node's props carry the layout fractions:

PropMeaning
level0 hub, 1 family, 2 schema label, 3 variable label
start, spanPosition and width round the wheel, as fractions of 1
weightWitness count, floored at 1
sourcesThe true count, unfloored — 0 is possible and meaningful
sourceListThe source drawings themselves, so a tooltip can name them
statesEvery state of this concept. Ring 3 emits one child per entry
color, fillStraight off the :Family node, which got them from families.js

Because start and span arrive precomputed, the renderer does no domain reasoning — it turns fractions into arcs. Point it at a different tree and it draws that instead.

A concept with no :IN_FAMILY edge is not dropped — it lands under a family called Unfiled. A missing family is a real finding about the data and has to be visible. A query that quietly returns 23 of 24 rows is the failure this substrate exists to end.

The envelope is also valid Graph Tool input, so the same URL opens as a radial node-link tree if you ever want to check the Sunburst against a second renderer:

/tools/graph-tool-v22.html?url=%2Fprojection%2Fvocabulary%3Fdb%3Daspects16

9 · What it will not show

Causal edges are absent by construction. A sunburst partitions a disc, so every child has exactly one parent and there is nowhere to draw an arrow that returns to its origin. The Fixes-that-Fail loop cannot appear here at all.

This is not a backlog item. If edges are ever added the geometry will accept them and the resulting picture will assert relationships it cannot actually represent. The causal reading belongs to /projection/causal and the Graph Tool.

Also absent, for the same reason — one parent each:

  • Instances. A thing that happened has a date and a place; it is not a longer name for a concept, so it is not part of this contraction.
  • Which source drawing contributed what. The wheel sizes by how many; hover names them, but the geometry cannot show a concept in nine places at once. Ring 3 is already spoken for by the concept’s states.
  • Link families. They describe edges, and there are no edges here.

10 · Troubleshooting

SymptomCause and fix
Status reads offline snapshot in redThe API is not answering. Start it: python3 substrate/api.py. You are looking at baked-in data of the stated date.
no data for <db>That database is neither reachable nor in the snapshot. Check the name, and check Neo4j is running.
Endpoint 404s with no projection 'vocabulary'An older api.py is still holding port 8768 and never loaded the route. Find it with ps aux | grep api.py, kill it, and restart.
A wedge shows only …Working as intended — too thin for text. Hover or click it.
A family called Unfiled appearsReal finding: some concept has no :IN_FAMILY edge. Fix it in families.js and re-run seed.py; do not fix it in the picture.
Colours look wrong or greyThe :Family nodes are missing their palette. Re-run the seed, which reads tools/families.js as the one source.
Exported SVG has un-wrapped textShould not happen — font-family is written onto the root. If it does, the export was edited by something that stripped it.
