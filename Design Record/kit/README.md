# The Kit

The tools and methods of RCN, as things a person grabs. This folder is the third of the three deliverables: the Book (the Design Record, `../01-`…`13-*.md`) explains, the Field Guide (`../field-guide/`) sequences, the Kit equips.

- `pattern-language.md` — the thirty-two patterns on Alexander's model: each tool or method with its problem, its move, what it needs, its state (built / partial / paper), where to learn it, and its Basic / Intermediate / Advanced skill ladder. The seed of the RCN pattern-language book.
- `../diagrams/kit-pattern-language.rcn.json` — the patterns as a network, drawn in the RCN Graph Tool.

To come here: the SODOTO skill triples, one Basic / Intermediate / Advanced page set per pattern, as FedWiki pages; and the tool intros, manuals and decks gathered or pointed at from one place (today they live in `../../tools/` and `../../docs/`).
