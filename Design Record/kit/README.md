# The Kit

The tools and methods of RCN, as things a person grabs. This folder is the third of the three deliverables: the Book (the Design Record, `../01-`…`13-*.md`) explains, the Field Guide (`../field-guide/`) sequences, the Kit equips.

- `pattern-language.md` — the thirty-two patterns on Alexander's model: each tool or method with its problem, its move, what it needs, its state (built / partial / paper), where to learn it, and its Basic / Intermediate / Advanced skill ladder. The seed of the RCN pattern-language book.
- `../diagrams/kit-pattern-language.rcn.json` — the patterns as a network, drawn in the RCN Graph Tool.

- `tool-index.md` — where each tool's own intro, manual, deck and schema live. The Kit points at them; `tools/` and `docs/` in the repository stay the source of truth. Nothing is copied.
- `skills/` — the SODOTO skill triples, one Basic / Intermediate / Advanced page set per pattern, each page built on SODOTO's three gates. `skills/README.md` is the template; `skills/evsm-*.md` is the first triple, written as the model for the rest. Pipeline markdown, ready for the fedwiki-page skill.

Still to write: the other thirty-one triples; patterns for the Graph Composer, the Issue Polygon Map, the MORE outliner and the schema sunburst, which have intros and manuals and no pattern yet.
