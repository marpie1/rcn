Introduction User Manual Sunburst ↗ README

Every tool used to own its own file. The same concept — Effectiveness of ORG — lived in a graph JSON, a map, a timeline and sixteen separate drawings, and nothing anywhere could say those were the same thing. The substrate is the decision to stop having two answers to one question.

The sentence everything follows from

The substrate owns meaning. The file owns appearance. Neither pretends to own the other, and anything derivable is computed rather than stored.

Almost every design question answers itself from that sentence, and every bug found so far was a violation of it. That is not a slogan added afterwards — it is the test that has actually caught things.

WhatLives whereWhy
Schema label, the states of a concept, polarity, relation family, sourcesNeo4jMeaning. It has to merge across drawings.
Coordinates, colour, duplicate placements, node idsThe fileAppearance. It belongs to one drawing.
Gold, family colour, the fallback layoutNowhereDerivable. Storing it creates a second answer that can drift.

The third row is the one people skip. gold is never stored — it is size(sources) > 1, evaluated fresh on every request. Family colour is looked up from families.js. Storing either would mean two answers to one question, which is the thing this exists to end.

What a lens is

A projection is one named Cypher query returning one lens, in one envelope, always:

{ "nodes": [ {id, label, props, x, y, w, h, shape} ],
  "edges": [ {id, src, tgt, label, polarity, props} ] }

It is the Graph Tool's own schema, declared canonical so renderers read it with zero translation. No adapters. The renderers stay dumb — they draw shapes from data and know nothing about the domain. When a lens seems to need a custom renderer, the projection is usually wrong; fix the query, not the renderer.

That rule paid for itself when the driver wheel was built. Its rings mean causal distance rather than naming — a completely different tree — and the Sunburst needed no new geometry at all, because the projection emits fractions and the wheel was already dumb about what they mean.

/projection/schema

The substrate describing itself: node kinds, their properties, the relationships between them, with live counts. Derived, so it cannot go stale.

/projection/causal

The CLD reading. Its nodes are states, because a causal claim is about measured quantities.

/projection/structure

The ERD reading — part-of, is-a, acts-in, depends-on. Deliberately unsigned.

/projection/gold

The federation lens: who drew what, and where two hands met.

/projection/vocabulary

Family → concept → states, as a tree. Feeds the Sunburst.

/projection/drivers

Causality unrolled from one state into a tree, carrying the sign accumulated along each path.

/projection/subgraph/<name>

One drawing, exactly as its author drew it — and exactly what a save would write.

The claim being tested

Only the data grows. Three databases — a six-node reference, a twenty-five-concept signed CLD, and sixteen contributor drawings — are read by byte-identical Cypher. ?db= selects which graph, never which query. If a lens ever needs different queries for the bigger graph, the architecture was not proven at n=6, and we would rather know that now than at n=260.

The six-node reference is not a toy. It is hand-written, small enough to check by eye, and exercises every layer at once: all four vocabulary levels, the instance layer with real dates and coordinates, families, relation families, and the gold test. Its edges close the Fixes-that-Fail loop, so any change that breaks feedback structure breaks it visibly and immediately.

The four levels

Family
The eight — Setting, Institution, Aim, Doing, Outcome, Issue, Resource, Person. A node, generated from families.js, never a string on a concept.
Concept
The merge key. Problem, Org, Action — what two drawings agree on even when they word it differently.
State
A way the concept is measured. Seriousness of PROBLEM. A node, not a property, because a concept can have several — and in OPM terms these are exactly the states of an object.
Instance
A thing that happened, with a date, a place, and someone who reported it. The backyard chicken ordinance dispute, Superior AZ, March 2026.

The first three are vocabulary — progressively longer names for the same idea. An instance is not a longer name, which is why it gets its own node, and why geometry and time intervals attach there. "Seriousness of PROBLEM" has no location; a chicken ordinance dispute does.

Where an edge attaches, and why it matters

Causal edges join states. Structural edges join concepts. That is not tidiness — it is the difference between two kinds of claim:

(:Variable)-[:REL]->(:Variable)   causal      "Coherence of PURPOSE raises
                                               Effectiveness of ORG"
(:Concept) -[:REL]->(:Concept)    structural  "an Org exists for a Purpose"

The second is true however effective the org is. Push it down to states and it says something nobody meant. The first is about measured quantities and cannot live anywhere else — one drawing records that Positive AFFECT raises motivation and Negative AFFECT lowers it, and while both hung off the concept only one of those claims could survive.

What it refuses to do

  • RefusesStore layout. Where a node sits belongs to a drawing, not to the shared graph. Coordinates travel file → tool → file and never pass through Neo4j.
  • RefusesStore what it can compute. Gold, family colour, a family's weight — all recomputed on every read, so none of them can disagree with the thing they describe.
  • RefusesInfer what only a human knows. Nothing in a list of strings separates merchant (a person) from action (a topic), so each loader declares it. Guessing put a false claim into three published documents once already.
  • RefusesGuess a relation family. Seventeen edges have none. They are counted and left alone, because a missing family is somebody's decision still to make.
  • RefusesLet one contributor delete another's work. A save retracts, then re-asserts: drop this drawing from every sources list, delete only what has no witness left, insert what was sent. Submitting an empty drawing deletes nothing anyone else drew.
  • RefusesBe edited in the Browser. Families and relation families are generated copies of families.js and edge-families.js. Editing them in Neo4j survives until the next load and then vanishes, with no error.

What it has caught

Each of these shipped, looked like working code, and was found by the ownership rule. They are recorded because the pattern matters more than the individual bugs.

A silent success that drew nothing

Coordinates were left out of a projection. The Graph Tool reported a clean load of 6 nodes and 7 edges and rendered an empty canvas. No error, at any layer.

A diff nobody would read

The database has no opinion about the order of a set, so emitting rows in Cypher order rewrote whole files — 44 insertions for a one-character change. The writer now keeps the file's own order.

A merge key that did not merge

One drawing writes Active Goal, another ActiveGoal. Unnormalised, that is one concept splitting into two nodes that never merge and never go gold. A merge key that does not normalise is not a merge key.

A concept that could hold only one meaning

A state was a single property, so a drawing containing both Positive and Negative AFFECT lost one on load — and the arbiter was string length. Longest wins, ties to whichever was read first.

A save that would have deleted every causal edge

When causal edges moved to states, the file writer still queried only concept-level edges. Previews of three drawings came back with zero edges. Caught by previewing all sixteen before writing anything — which is the only reason it never reached disk.

An invented self-loop

A drawing places one concept twice so its edges do not cross. Collapsing those placements turned an edge between two different nodes into an edge from a node to itself. Nobody drew a self-loop; merging invented it.

The bet underneath

A neighborhood cannot reason about itself while every tool holds a private copy of the same words. Put the meaning in one graph, keep the appearance in the files people actually drew, compute everything that can be computed, and refuse to guess the rest — and the tools stop being applications you have to reconcile and start being questions you can ask of one thing.

Six lenses so far. The next one costs a query, not an application.
