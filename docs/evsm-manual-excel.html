Excel Tool

Convert between eVSM JSON and Excel workbooks. Use familiar spreadsheet software to write and review survey content, then bring it back into the eVSM tools.

evsm_excel_tool.html

Overview

The Excel Tool bridges the eVSM JSON format and Microsoft Excel (or any application that reads .xlsx files). It has two uses:

  • Export (JSON → Excel) — take an existing eVSM config JSON and produce a structured workbook. Edit the content in Excel, then import it back.
  • Import (Excel → JSON) — take a filled-in workbook and produce a config JSON ready to load into the Survey Tool.
The Excel Tool is for survey design only. It handles sphere labels, descriptions, edge descriptions, and world categories. It does not import or export respondent assessment data (status, evidence, suggestions from respondents).

Exporting JSON to Excel

  1. Open evsm_excel_tool.html in your browser.
  2. In the Export JSON → Excel card, paste your eVSM config JSON into the text area. If you are starting from scratch, click Load Sample JSON to populate it with a working example.
  3. Click ⬇ Export to Excel.
  4. A file named NDC_Sofi_Setup.xlsx downloads to your computer.
  5. Open it in Excel, Google Sheets, or LibreOffice Calc.

Click Clear to empty the text area and start over.

The Excel Workbook Structure

The exported workbook has five sheets:

Survey Meta
Two columns: Field | Value
Contains all survey metadata fields: Enterprise, Focal Point, Date, Time Frame, Survey ID, Respondent ID, Anonymous Mode. Edit the Value column to change any of these.
Spheres
Columns: ID · Label · Layer · Anatomical Framing · Vernacular Description · Status · Notes
One row per sphere (S-1 through S-11). Edit the Label to rename a sphere. Write the sphere's description across two columns:
  • Anatomical Framing — the systems-theory or structural description (appears as italic text in the tool)
  • Vernacular Description — the plain-language, community-facing description (appears as bold text in the tool)
The Layer column is automatically set based on sphere ID and should not be edited. Status and Notes are optional planning fields.
Edges
Columns: From · To · Edge ID · From Label · To Label · Anatomical Framing · Domain Assertion · Status · Evidence/Example · Suggestion
One row per relationship. The From and To columns use sphere IDs (S-1, S-2, etc.). Write edge descriptions across two columns:
  • Anatomical Framing — the structural description of this relationship (appears as italic)
  • Domain Assertion — the statement of what this relationship should accomplish (appears as bold)
From Label, To Label, and Edge ID are read-only reference columns auto-filled from the Spheres sheet.
Worlds Categories
Columns: # · Category · Notes
One row per world category. Add, remove, or rename categories in the Category column. Order is preserved in the import.
Layer Reference
A read-only reference table explaining the three sphere layers (Sensory/Interface, Internal Core, Alignment/Homeostatic) and the Markov Blanket concept. Do not edit this sheet — it does not affect the import.

Importing Excel to JSON

  1. After editing the workbook, save it as .xlsx (not .xls or .csv).
  2. In the Import Excel → JSON card, click 📂 Choose Excel File and select your workbook.
  3. A preview table appears confirming what was read: number of spheres, number of edges with content, number of world categories, and survey metadata.
  4. Click ⬇ Download JSON to save the result as NDC_Sofi_export.json.
  5. Load this file into the Survey Tool via the Import button in Setup mode.

How Descriptions Are Converted

The Excel Tool splits and recombines description text between markdown (used in the Survey Tool) and two separate columns (used in Excel):

In JSON (Survey Tool) In Excel
_This is italic text_ Anatomical Framing column: This is italic text
**This is bold text** Vernacular Description (or Domain Assertion) column: This is bold text
Both italic and bold together, separated by a line break Both columns filled; combined on import back into _italic_\n**bold**

This means you should write one type of text per column — do not put both italic and bold content in the same column cell.

Error Messages

MessageCause and fix
❌ Invalid JSON — please check your input.The text in the export textarea is not valid JSON. Check for missing brackets, quotes, or commas.
❌ Error reading file: {message}The Excel file could not be parsed. Ensure the file is saved as .xlsx and has the expected sheet names.

Tips

  • Start from the sample JSON rather than writing a config from scratch. Click Load Sample JSON, export to Excel, and edit from there.
  • After importing and downloading the JSON, load it into the Survey Tool's Setup mode to verify that the labels and descriptions appear correctly before distributing to respondents.
  • The workbook can be shared with co-designers who do not have access to the Survey Tool. They can fill in descriptions in Excel and return the file for import.
  • Google Sheets can edit .xlsx files — but save back to .xlsx format before importing, not as Google Sheets format.
