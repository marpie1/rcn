Introduction to the Vester Influence Analysis Suite

A nine-step method for understanding complex systems through biocybernetic analysis — implemented as an interoperable set of participatory tools.

What is the Vester Sensitivity Model?

Frederic Vester's sensitivity model (Sensitivitätsmodell) is a structured group process for understanding complex systems, developed from his work at the Study Group for Biology and Environment and formalized in The Art of Interconnected Thinking (2007). It has been applied to corporate strategy, regional planning, healthcare, risk management, urban design, and counter-terrorism analysis.

The core insight: complex systems cannot be understood by analyzing parts in isolation. Optimizing individual variables often destroys systemic balance. Only by mapping influence relationships across the whole can leverage points, instabilities, and safe intervention strategies be identified.

Vester's method is explicitly participatory — the matrix scoring, criteria assessment, and lookup table construction are designed to be done by a group, not by an analyst. The model that emerges is owned by the group, not imposed on it.

The Nine Steps

  1. System Description — Define the problem, purpose, and system boundary in plain language. Who is affected? What is inside vs. outside?
  2. Variable Set — Identify 20–30 key variables. Describe each and define a 0–30 measurable scale with observable anchor points and an optimum if relevant.
  3. System Criteria — Assess each variable against 24 criteria in 5 groups (Spheres of Life, Physical, Dynamical, System Relationships, Corporate Performance Criteria). Reveals the character of each variable in the system.
  4. Cross-Impact Matrix — Score pairwise influence: how strongly does variable A influence variable B? (0=none, 1=weak, 2=medium, 3=strong). Active Sum = row total; Passive Sum = column total.
  5. System Roles — Plot variables on the Active Sum × Passive Sum quadrant. Classify as: Active (high AS, low PS), Passive/Indicator (low AS, high PS), Critical/Reactive (high both), or Buffering (low both).
  6. Partial Scenario — Select 2–4 leverage variables (typically Active or Critical). Define alternative states and trace first-order consequences through the matrix.
  7. Stock & Flow Diagram — Translate variable relationships into a formal structure of stocks, flows (valves), auxiliaries, and clouds — the structural layer for simulation.
  8. Lookup Table Curves — Replace mathematical equations with group-constructed graphical functions (Vester's "biokybernetik" curves) that capture qualitative expert knowledge about how variables relate.
  9. Simulation — Run the model using Euler integration reading from lookup tables. Test interventions. Evaluate results against Vester's 8 biocybernetic basic rules.

The AS×PS Quadrant

After the cross-impact matrix is scored (Step 4), every variable receives an Active Sum (total influence it exerts) and a Passive Sum (total influence it receives). Plotting these two values places each variable in one of four roles:

Low PS High PS
High AS
Active
Strong drivers with few feedbacks. These are the levers — they push the system but are relatively insensitive to it.
Critical
High leverage, highly influenced — the most dangerous to disturb. Both cause change and absorb it; small interventions can cascade unpredictably.

Buffering
Stable dampers that absorb shocks without amplifying them. Preserve these — disrupting them can destabilize the whole system.
Passive / Indicator
Result variables — they respond to the system but do little to drive it. Measure outcomes here; do not intervene here.

Active variables are levers. Passive variables are indicators. Critical variables are the most dangerous to disturb — they are both highly influential and highly influenced. Buffering variables provide stability; disrupting them can destabilize the whole system.

The "Control the Whole Space" Requirement

Because variables must be the same objects across the Vester app, the SFD, simulation, and reporting — changing a variable in one place should update it everywhere. This cross-tool variable identity is the architectural goal driving the interoperability design.

Variable names are the shared key. The JSON export from the Vester app carries variable IDs that the SFD mode and simulation layer can reference directly. Renaming a variable in the Vester app and re-importing updates the full downstream chain.

Vester's Eight Biocybernetic Basic Rules

These rules run as a diagnostic thread throughout the process and are applied formally in Step 9. A system that scores well on all eight rules is a biocybernetically mature system.

  1. Negative feedback must dominate over positive feedback
  2. System function must be independent of quantitative growth
  3. Function-oriented, not product-oriented
  4. Exploit existing forces (ju-jitsu principle)
  5. Multiple use of products, functions, and structures
  6. Recycling — circular processes
  7. Symbiosis — reciprocal use of differences
  8. Biological design through feedback planning
These rules are not a checklist applied at the end — they inform modeling choices throughout the process. When a proposed intervention violates rule 1 (amplifies positive feedback) or rule 2 (requires growth to sustain function), the model surfaces that tension before it becomes a real-world failure.

About This Project

The RCN implementation adapts Vester's method for Neighborhood Development Cooperative work. The pilot application is the Superior AZ NDC. The participatory emphasis is deliberate: the tools are designed for workshop use, not individual analysis.

Vester developed the sensitivity model specifically because technical experts working alone tend to produce models that communities cannot interrogate or own. The workshop format — where variable definitions, matrix scores, and lookup curves are all produced by the group in the room — is not a concession to participation. It is the epistemological core of the method.
