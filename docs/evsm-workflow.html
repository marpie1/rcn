Workflow Between Tools

How the four eVSM tools connect in a complete survey cycle, from design through synthesis.

Overview

A complete eVSM engagement moves through six phases. Three roles are involved: the Facilitator who designs and runs the survey, the Respondent who completes assessments, and the Analyst (often the same person as the facilitator) who synthesizes results.

All data exchange between tools happens via JSON files that participants download and share. There is no central database or login system.

The Six Phases

1
Design the Survey
Facilitator · Survey Tool (Setup mode) or Excel Tool

Define sphere labels and descriptions, edge descriptions, survey metadata (enterprise name, time frame, focal point), and world categories. Two paths are available:

  • In the Survey Tool directly: Open evsm-svg-v3.html, switch to Setup mode. Edit sphere labels, enter descriptions, add world categories.
  • Via Excel: Open evsm_excel_tool.html, click "Load Sample JSON" to start from a template, export to Excel, fill in the spreadsheet, then import back to JSON.

When design is complete, export a config JSON from the Survey Tool. This file contains all labels, descriptions, and world categories — but no respondent assessments.

evsm-config.json — shared with all respondents
2
Distribute to Respondents
Facilitator

Primary path — Snapshot: In Setup mode, click ⬇ Snapshot (share as one file). This bakes the current config directly into a copy of the Survey Tool HTML and downloads it as {surveyid}-survey.html. Share that single file with respondents via email or a shared drive — they open it in their browser and land directly in Survey mode, no config import needed. Setup is still accessible via the tab if they need it.

Alternative path: Host the Survey Tool on a web server and email the config JSON + link. Respondents import the config manually when they open the tool. This path works but is more friction for respondents.

Do not send the Snapshot HTML via WhatsApp — WhatsApp may corrupt the file. Use email or a shared drive (Google Drive, Dropbox, etc.).
3
Complete the Survey
Respondent · Survey Tool (Survey mode)

Each respondent opens the Survey Tool, imports the config JSON the facilitator provided, and works through the assessment:

  1. Enter name (or work anonymously)
  2. Check applicable world categories
  3. For each sphere and relationship: choose a status, add evidence and suggestions
  4. The tool auto-saves in the browser — respondents can close and resume later
  5. When finished (or at any point), click Export to download a response JSON

Optionally, respondents can generate a personal Respondent Report (see Phase 3b below) before submitting.

evsm-response-{name}-{timestamp}.json — returned to facilitator
3b
Generate Personal Report (optional)
Respondent · Respondent Report

At any time, a respondent can click ⎙ Print My Report in the Survey Tool. The tool fetches evsm-report.html, bakes their response data into it as a blob, and opens it in a new tab — no file download or upload required. Both evsm-svg-v3.html and evsm-report.html must be in the same folder for this to work.

If the automatic path fails, they can open evsm-report.html directly and drag their exported response JSON onto the drop zone. The report can be saved as a PDF via the browser's print dialog.

4
Collect Response Files
Facilitator

Gather all respondent JSON files (via email, shared folder, or any file-sharing method). You do not need all responses at once — the Aggregator lets you load more files at any time and the diagrams update immediately.

5
Aggregate and Analyze
Analyst · Aggregator

Open evsm-aggregator.html and drag all response JSON files into the drop zone. The aggregated diagram appears automatically, coloring each sphere and edge by the distribution of responses. You can also drop a master config JSON first (before any respondent files) to seed the sphere labels without adding assessment counts.

Single view: click any sphere or edge to see the breakdown of assessments and read all respondents' evidence and suggestions.

Compare view: define two world sets (e.g., "Longtime residents" vs. "New arrivals") and view side-by-side diagrams to see where assessments differ.

Claude synthesis (per element): click "Synthesize with Claude" on any selected element to get a narrative summary of what respondents said, highlighting convergence and divergence. Requires your Anthropic API key (stored in localStorage; calls go directly to Anthropic — no proxy needed).

✦ Synthesize All: click the purple header button to run Claude sequentially for every sphere and relationship that has at least one assessment. A progress overlay shows status with a cancel option. Syntheses are cached in memory.

⬇ Export Session: click the amber header button to save everything as a single JSON bundle — all loaded response files, sphere labels, edge descriptions, world set configuration, and all Claude syntheses generated so far. Drop a session bundle back onto the drop zone to restore the full session instantly.

⎙ Print: click the green header button to print the current detail panel using the browser's print dialog.

Respondent identity features: hover over any sphere or edge to see a floating panel listing each respondent's name and status choice. Click a name in the hover panel (or in the respondent list) to filter evidence and suggestion quotes to that person. Click ⇄ beside any name to jump to Compare mode showing that individual's diagram vs the aggregate. Toggle ⊙ Show Names in the header to label all quotes with respondent names.

6
Synthesis and Reporting
Analyst / Facilitator

Click ⎙ Full Report (blue header button) to open the sphere picker, choose which of the 11 spheres to include, and generate a standalone HTML Homeostatic Pairs Report in a new tab. The report is organized by focal sphere — one page per sphere — each containing: a focus diagram (full eVSM SVG with only the focal sphere and its neighbors colorized), the sphere's assessment data, and a Homeostatic Pairs section showing both directions of every regulatory relationship involving that sphere. Unassessed connections appear as bold black arrows. Items without a synthesis still appear without the synthesis block.

Individual respondent reports from Phase 3b can also be shared back with participants — they follow the same homeostatic pairs structure. If you need to revise sphere labels or descriptions for a follow-up survey, use the Excel Tool to export the config, edit in Excel, and reimport.

Data Flow Summary

Common Variations

Small group, facilitator present

The facilitator opens the Survey Tool on a shared screen or hands a laptop to each participant. No file distribution needed — each person completes the survey, exports their response file, and hands the laptop back. The facilitator aggregates on the spot.

Remote / asynchronous survey

The facilitator hosts the Survey Tool on a web server and emails the config JSON + link to participants. Respondents complete the survey at their own pace, export their response file, and return it by email or shared drive.

Iterative design with Excel

For large or complex surveys, design the sphere descriptions in Excel where it is easier to write and review long text. Import to JSON, load into the Survey Tool to verify layout, make adjustments, export config again as needed.

Partial responses

Respondents can export their response file at any time — even before completing all assessments. The Aggregator handles partial responses: it only includes an assessment in the count if the respondent chose a status for that element.

Tool Compatibility Notes

  • All four tools run entirely in the browser. No server installation is required. The Aggregator calls the Anthropic API directly using the user's own API key (stored in localStorage).
  • Response files from one version of the survey can be loaded into a different config version — the Aggregator reads whatever fields are present.
  • There are two report types: the Respondent Report (evsm-report.html — one person's data, opened from the Survey Tool's Print button via blob URL or by drag-drop) and the Aggregate Full Report (generated by the Aggregator's Full Report button — all respondents combined, with Claude syntheses). The Print button in the Survey Tool uses a blob URL and works reliably for local files as long as both HTML files are in the same folder.
  • The Excel Tool is for survey design only — it does not import or export respondent assessments.
