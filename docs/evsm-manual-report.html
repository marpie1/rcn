Respondent Report

Generate a formatted, print-ready report of a single respondent's complete assessment. Save as PDF or print on paper.

evsm-report.html

Overview

The Respondent Report takes a single eVSM response JSON and renders it as a clean, readable document organized by sphere. It is used in two situations:

  • By the respondent, immediately after completing a survey, to review their own assessments and create a personal record
  • By the facilitator, to produce individual reports that can be shared back with each participant after the survey is complete

The report contains no aggregated data from other respondents — it reflects one person's assessments only.

Opening the Report

From the Survey Tool (automatic)

The easiest way to open the report is from within the Survey Tool. While in Survey mode, click the Print button in the left panel. This opens the Report tool in a new browser window with your current data already loaded. No file download or upload is required.

Directly (drag-and-drop)

  1. Open evsm-report.html in your browser.
  2. A load screen appears with a drop zone.
  3. Drag your response JSON file onto the drop zone, or click Choose Response File to browse.
  4. The report renders immediately.

The report is organized into the following sections:

Header block

Shows survey metadata: enterprise name, respondent name or ID, date, time frame, survey ID, world category tags, and the focal point text (if the facilitator provided one).

Sphere sections

One section per sphere, in order S-1 through S-11. Each section shows:

  • The sphere's name and a colored status indicator dot
  • The respondent's status choice (Go / Caution / Stop / Unsure)
  • Evidence text (if provided)
  • Suggestions text (if provided)
  • All outgoing relationships from that sphere, each showing the respondent's assessment (Agree / Disagree / Unknown), evidence, and suggestions

If a sphere or relationship was not assessed, the report shows "Not assessed" for that item.

Footer

Timestamp showing when the report was generated.

Printing and Saving as PDF

  1. Once the report is displayed, click the ⎙ Print / Save PDF button in the lower right corner of the screen.
  2. Your browser's print dialog opens.
  3. To save as PDF: select "Save as PDF" (or "Microsoft Print to PDF") as the destination.
  4. To print on paper: select your printer and click Print.
For best results when saving as PDF, use Chrome or Edge and set paper size to Letter or A4 with default margins. The report is styled to paginate cleanly at sphere boundaries.

Loading a Different Response

Click ← Load Another in the lower left corner to return to the load screen. This discards the currently displayed report and lets you load a different response file.

Error Messages

✗ Could not read file — is it a valid eVSM response JSON?The file does not have the expected structure. Make sure you are loading a response JSON exported from the Survey Tool, not a config JSON.

Notes

  • The Report tool can only display one respondent at a time. To analyze multiple respondents together, use the Aggregator.
  • If a respondent's name is not available (anonymous survey), the report shows their respondent ID or "Anonymous."
  • All text is selectable — you can copy evidence or suggestion text from the report directly.
