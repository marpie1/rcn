# Four Kinds of Sequence

The frameworks read for [[Six Questions Five Pathways]] contain sequences of four genuinely different kinds. Flattening them into a single list of methods is the biggest error available here, because they are used at different moments and answer to different tests.

DIAGRAM_rcn-four-sequences

## Ontological

What is true of ethical collective action. Not performed — a claim about how persons, ideals, organizations and actions necessarily relate, and about what makes their relating come to good. You check yourself against it and find which relation has failed.

Examples: [[The Two Governing Models]], the Optimum Sequence, [[AIC]].

## Diagnostic

What to do when you are stuck. A routing procedure that takes an unclear situation and returns a type, a scale, and a decision about which production sequence to enter. The kind people most need and the kind least often written down.

Examples: [[Systemic Problem Solving]], [[Cynefin]], [[The Six Nested Questions]], [[Six Thinking Hats]], [[DSRP]].

## Production

Getting a thing built, delivered and taught. Ordered work with resources, handoffs and deliverables. These look like conventional method documentation and are the least transferable, each being fitted to a domain.

Examples: [[15 Ps]], [[Another Sequence of Tools]], [[Vester's Sensitivity Model]], the System Discovery Process.

## Curricular

The order in which a person learns the skills. A learning progression is not a work progression: causal loop diagramming, then stock flow, then system dynamics, then Vester is how you acquire the practice, and nobody would run a project in that order. This is the kind [[SODOTO]] actually certifies.

Examples: the six pathways already named in the SODOTO Skills Registry, and the four levels of the [[Systems Curriculum]].

## How they connect

All four are patterns in Alexander's sense, at different scales. The diagnostic pathway selects a production pathway. The curricular pathways say who is qualified to run either. The ontological frame is what all of it is checked against.
