# Systemic Problem Solving

**Problem:** A neighbourhood problem keeps resisting the obvious fixes, and nobody agrees on what kind of problem it even is.

**Context:** The front door. Entered when handy heuristics have failed, and before any production pathway is chosen. This is the router — it chooses the others.

Kind: diagnostic. Confidence: one star. Fallback: drop back to a causal loop diagram. See [[The Causal Ladder]].

## 1. Will a rule of thumb do?

Try the handy heuristics first. Most things are not systems problems and should not be treated as one.

**Gate:** proceed only when the simple heuristics have actually failed. Entering the full pathway on a problem that did not need it is how these methods get a reputation for ceremony.

## 2. What is connected to what?

Draw the problem situation, naming the nodes and the connections. Start on pen and paper; move to the Graph Tool only once something interesting shows up.

The drawing exists to be argued with, not to be correct.

**Hands off:** a graph JSON with named nodes and named edges. Everything downstream reads this, and it is the rung you return to from anywhere.

## 3. What kind of problem is each part of this?

Type each subgraph separately with [[Cynefin]] — simple, complicated, complex, chaotic, disordered. A neighbourhood problem is almost never one type throughout, and the parts want different treatment.

**Routes to:** complicated goes to design and engineering tools and [[Inspiration to Implementation]]. Complex goes to [[Shared Understanding to Experiment]]. Chaotic means act first, stabilise, then retype.

## 4. When, where, why, who, how, and only then what?

Work [[The Six Nested Questions]] in order, with the people who actually hold the situation. Two to four hours.

The order is load-bearing. Answering What first is the standard failure, and it produces solutions nobody will carry.

**Gate:** the stakeholders must be in the room. Run alone, this step produces a document rather than a shared understanding, and the pathway depends on the second thing.

## 5. Where is our power, and are we using all three kinds?

[[AIC]] — equal time appreciating the whole situation, weighing the diverse valuations stakeholders hold, and designing production and control.

The magic is in keeping attention on all three domains, so that the most power possible can be applied.

Appreciate maps to Ideals, Influence to Persons, Control to Orgs and Action — the vertices of [[The Two Governing Models]], and the three sources of legitimate power from [[Empowering Change Agents]].

## 6. Would running this be beautiful, good, true and economical?

The crown check, before committing. Not a formality: a plan that is efficient and ugly, or effective and untrue to the ecology it sits in, fails here and should not proceed on the strength of having passed everything else.

## 7. Which pathway now, and who has the standing to run it?

The output is not a solution. It is a typed, scaled, shared understanding, a choice of production pathway, and a check of whether anyone present is certified in the skills that pathway needs.
