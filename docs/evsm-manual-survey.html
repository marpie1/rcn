Survey Tool

Design the survey and collect individual respondent assessments. Used in two distinct modes: Setup (facilitator) and Survey (respondent).

evsm-svg-v3.html

Overview

The Survey Tool is the starting point for every eVSM engagement. It serves two roles in one file:

  • Setup mode — used by the facilitator to configure sphere labels, descriptions, world categories, and survey metadata. Produces a config JSON file shared with respondents.
  • Survey mode — used by respondents to work through assessments of all eleven spheres and their relationships. Produces a response JSON file returned to the facilitator.

The tool switches between modes using the tabs in the header bar. The same config JSON is used in both modes — respondents import it to begin the survey.

Setup Mode

Setup mode is for facilitators. Use it to define the content of the survey before distributing it to respondents.

Survey Identity

Fill in the fields in the upper portion of the left panel:

FieldPurpose
EnterpriseName of the organization or neighborhood being assessed

Sphere Labels

The left panel lists all eleven spheres (S-1 through S-11). Click any label field to rename a sphere. Labels support line breaks — press Enter within the field to wrap text into multiple lines as it appears in the diagram.

Diagram Display Controls

Four sliders adjust the visual appearance of the SVG diagram:

SliderEffectRange
RadiusSize of the sphere circles15 – 90 (default 45)

Changes apply in real-time. These settings are stored in the exported config JSON.

Sphere and Edge Descriptions

Click any sphere or edge in the diagram (or click the sphere label in the right panel's element list) to open the detail editor on the right. You can:

  • Write a description in the text area — this is what respondents see when they assess this element. Supports basic markdown: **bold** and _italic_.
  • Set a preliminary status — useful for planning, not part of respondent output.

World Categories

In the Worlds section of the left panel, define the demographic and role categories relevant to your survey population. Examples: Longtime resident, Under 30, Business owner, Renter.

  • Type a category name and press Enter or click Add to create it
  • Click an existing tag to edit its name inline
  • Drag tags to reorder them
  • Click × on a tag to delete it

Exporting the Config

When your setup is complete, click Export Config in the left panel. This downloads a sofi-config.json file. Send this file to all respondents — it is everything they need to start the survey.

The config JSON contains no respondent assessments — only the structure, labels, descriptions, and metadata you defined. It is safe to share publicly.

Survey Mode

Survey mode is for respondents. To switch to it, click the ◎ Survey tab in the header. Respondents should import the facilitator's config JSON before beginning.

Starting the Survey

  1. Click Import and select the config JSON file the facilitator sent you. The sphere labels and descriptions will load.
  2. Enter your name in the Respondent Name field (or leave blank if the survey is anonymous).
  3. In the My Worlds section, check all categories that apply to you. These tags will be attached to your response and used to filter results in the Aggregator.
  4. Begin the assessment — click any sphere or edge in the diagram, or use the navigation list in the left panel to move through items in order.

Completing an Assessment

When you click a sphere or relationship, the right panel opens an assessment form with three parts:

  • Description — the facilitator's text explaining what this sphere or relationship means in the context of your organization.
  • Status — choose one option from the dropdown. See status definitions below.
  • Evidence / Example — describe a specific situation, observation, or example that supports your assessment.
  • Suggestions for Improvement — optional; write what you think should change or be strengthened.

All fields save automatically as you type. You do not need to click a Save button.

Node (Sphere) Status Options

Go — functioning well Caution — needs attention Stop — urgent concern Unsure — don't know

Edge (Relationship) Status Options

Agree — relationship is working Disagree — relationship is blocked Unknown — can't say

Navigating the Assessment

There are three ways to move between items:

  • Click the diagram — click any sphere or arrow directly
  • Navigation list — the left panel shows all eleven spheres followed by all relationships, each with a colored dot indicating whether it has been assessed. Click any item to jump to it.
  • Previous / Next buttons — at the bottom of the right panel assessment form, these move sequentially through all items in order.

Progress Bar

The header shows a progress bar and a count (e.g., 23 / 77) reflecting how many items have been given a status. There are 11 spheres and 66 directed relationships, for a total of 77 assessments. You do not need to complete all of them — partial responses are accepted.

Exporting Your Response

Click Export to download your response as a JSON file. The filename includes your name and a timestamp: sofi-response-{name}-{timestamp}.json. Send this file to the facilitator. You can export at any time — mid-survey exports capture your progress so far.

Resuming a Partial Survey

The survey auto-saves your work in the browser's local storage — if you close the tab and reopen the tool, your previous session will be offered. You can also click Import and load a previously exported response JSON to continue from where you left off.

Printing Your Report

Click Print to open the Respondent Report tool with your data pre-loaded. This generates a formatted, print-ready summary of all your assessments. Use the browser's print dialog to save as PDF.
