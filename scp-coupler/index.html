How the coupler works

Your work saves automatically

Every entry you record and every frame the AI generates is written to disk on this machine as soon as you save or generate it. There is nothing to manually save. Close the browser, restart the proxy, come back — select the same person and problem and everything is exactly where you left it.

Two kinds of export — different purposes

Save Bundle — the portable backup format. Downloads a single .json file containing the full state for a person: all problems, all record entries, all frame versions including history. Use this to move work between machines, hand off to a colleague, or keep an archive. Load it back with Load Bundle — it restores everything and adds the person to the sidebar if they aren't already there.

FedWiki — a one-way clinical view. Exports the current problem's frame as a FedWiki-format page for import into the Shared Care Plan or a Groove workspace. It is not designed to come back in as coupler data — it is a clinical document for a care team.

Toolbar buttons

  • Generate Frame — asks the AI to build the full workup frame for this problem from scratch, using any record entries already present. Creates a new saved version.
  • Re-Match — takes the existing frame and any new record entries you've added, and asks the AI to update every slot's status (filled / partial / absent) and re-estimate probabilities. Appends to the probability history — nothing is overwritten. Use this each time you add new findings.
  • Narrate — generates a plain-language paragraph: what we know, what's missing, what the gaps mean. Updates the summary box at the top of the problem view.

Entering findings

Click any finding row in Subjective or Objective to open the entry form. Fill in the value, who recorded it, and the date. Check "Written by other" if the person of record did not record this themselves. Entries save immediately. Then click Re-Match to see probabilities update.

Attention codes

Each candidate assessment carries a code 1–5 computed from two inputs: how likely it is (probability band A–D) and how bad it would be to miss (severity class I–IV). The code is a deterministic table lookup — the AI never assigns it. Codes 1 and 2 always surface at the top of the page regardless of probability rank.
